# KITT source audit, 11 September 2026

## Original user link

[Knight Rider KITT (Supercar), FG / FGraphic](https://sketchfab.com/3d-models/knight-rider-kitt-supercar-e6c147a0d2c54bdbb101b56fa61646fe)
was inspected in the user's signed-in Sketchfab browser session. The page shows
988.5k triangles and 503.5k vertices. Its author says the base model was purchased
from Hum3D, modified, and displayed for illustrative purposes. There is no download
button. This is not a source asset acquired for OpenCity.

## Downloadable alternative

[Pontiac Firebird KITT, Nieve5677 / niev](https://sketchfab.com/3d-models/pontiac-firebird-kitt-a162ef66ffde4e23b3b49b03e7504507)
shows a CC Attribution 4.0 license, a download button, 951.2k triangles and 532.9k
vertices. The download dialog explicitly permits commercial use with attribution.
Formats shown: original OBJ 76 MB, USDZ 14 MB, glTF 12 MB and GLB 29 MB.

The visible license points to https://creativecommons.org/licenses/by/4.0/.
Required credit if eventually used: Pontiac Firebird KITT by Nieve5677, linked
to the model and license, with OpenCity optimization/rigging changes identified.
This is the publisher's license declaration, not a claim of manufacturer CAD.

The GLB download was attempted through the normal download dialog. Chrome
displayed ERR_BLOCKED_BY_CLIENT for the file host. No KITT file appeared in the
download folder. No direct-host workaround was attempted. Geometry, materials,
separable wheels and suitability for reduction to the game budget remain unverified.

The website's embedded viewer also reported that the model was too heavy for
this device. A triangle count alone is not evidence that it can be decimated to
25,000 triangles while retaining acceptable appearance. Download and Blender
inspection must precede any such acceptance claim.

## Current game

No external KITT asset was imported or substituted. The original Blender
workshop candidate and current live KITT remain as documented separately.
